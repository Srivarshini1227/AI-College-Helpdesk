About This Project

AI College Helpdesk is a portfolio project built with plain HTML, CSS and vanilla JavaScript. It runs in the browser with no backend, database or paid API.

  • The chatbot is rule-based keyword matching over a local FAQ dataset.
  • All notices, events, FAQs and contacts are sample data and should be replaced with verified information.
  • The answer logic is isolated in one provider object so a real AI API and retrieval-augmented generation (RAG) backend can be added later.

Admin Demo Panel

Security warning: this admin panel is a frontend demo only. It has no secure authentication and must not be used to manage real official college data without a backend and proper authorization.
